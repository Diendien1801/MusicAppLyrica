# 🎵 Lyrica

**Lyrica** is a mobile music streaming application built with Flutter, offering an engaging interface and smooth user experience. It supports music playback, playlist management, user profiles, and song uploads — all powered by Firebase and managed with GetX for efficient state handling.

## 🛠 Requirements

Before running the project, make sure you have:

- ✅ [Android Studio](https://developer.android.com/studio) installed (for device emulator).
- ✅ [Visual Studio Code](https://code.visualstudio.com/) installed.
- ✅ Flutter SDK configured (if using Flutter).
- ✅ A working Android Emulator **or** a physical Android device connected.

> **Note:** Ensure that the device (virtual or physical) is detected by running `flutter devices` or `adb devices` in your terminal.

---

## ▶️ How to Run

1. Open the project folder in **Visual Studio Code**.
2. Make sure an emulator is running **or** your phone is connected and recognized.
3. Click on `Run` > `Start Debugging` in the top menu bar.
   - Or simply press **F5** to start the app.

---

## 📦 Troubleshooting

- If no device is detected, try opening **Android Studio**, launch a virtual device (AVD), and re-run.
- Ensure USB Debugging is enabled on your phone if using a real device.
